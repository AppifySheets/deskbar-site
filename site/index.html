Deskbar for Windows 11 and Claude Code

Every Claude session, on one bar.

Hand a task to Claude Code from the bar. Each session works in a workspace of its own, keeps its task up to date, and asks you through it when the next move is yours. The bar shows which session is working, which finished and which is waiting on you, and one double-click takes you there.

Underneath is a taskbar for Windows' own virtual desktops: every desktop's windows at once, named and coloured. Hold Win+Ctrl and tap Tab to switch.

With Claude Code

Hand it over. Get called back.

Deskbar is built for running many Claude Code sessions at once. Every session keeps a task on the bar, and that task is how you and the session talk: what it is doing, what it needs from you, and what it has finished. The Claude Code sessions page has the details.

  1. Hand a task to Claude

    Type a note into the box on the bar and pick Start Claude on this. A background Claude Code session starts in the task's folder, with the task as its first message, and opens a window. A session you start yourself, in VS Code or a terminal, joins a task or makes its own.

  2. It works in a workspace of its own

    Deskbar teaches every Claude Code session on the machine to open its links, programs and windows in its own workspace. Nothing it opens lands on the workspace you are looking at.

  3. You see where each one stands

    Each session keeps a short status line on its task. Tasks with a live session sit together under Claude working, and a pull request a session opens shows up on its task by itself.

  4. It asks you through the task

    When the next move is yours, the task turns orange and moves to Waiting on you with the question. The pull request or page to open is a link right there. A session that finishes or waits while you are elsewhere makes its workspace's name flash orange on the bar.

  5. One double-click to get there

    Double-click a task to land on its workspace with the session's window in front. A window that was closed opens again, attached to the session, and a session that had ended is resumed first.

  6. It marks it done, you close it

    A finished task gets a green tick, and only you close a task. Once a done task's background session has sat idle for a minute, Deskbar stops it and keeps the conversation, so a double-click brings it back.

With many sessions, nothing falls out of sight

  • Sessions come back after a restart

    When an open task's session is gone after a reboot, a crash or a closed VS Code window, Deskbar resumes it in the background and says so in the task's thread. One cut off mid-turn is told to carry on.

  • A stalled session comes back to you

    A Claude task no session has worked on for 15 minutes is handed back to you with Claude's last status line. A session that stopped at "ready to merge" without asking is not left out of sight.

  • A manager for the whole board

    The Manager button starts one background Claude session a day that reads every open task, nudges sessions that stopped and lists what waits on you. It acts only through task commands, and it cannot close, delete or finish a task.

Under every session

Every desktop, in one strip.

Windows has had virtual desktops for years, without names you can see or any memory of what goes where. Deskbar is a layer over them that adds what was missing.

  • All your windows, on every desktop

    One row per workspace, each with its name above the icons of every window in it. Click an icon to jump to that window wherever it lives, and click it again to put it away. Drag it to another row to move the window there.

  • Real desktops, with names and colours

    Every workspace is one of Windows' own virtual desktops. Quit Deskbar and your windows are still on their desktops, reachable through Task View exactly as before.

  • Each workspace keeps to itself

    While you are in one workspace, its windows are the only ones on your taskbar and the only ones Alt+Tab walks through. A screen share of one workspace shows nothing of the others.

  • Switch the way Alt+Tab switches

    Win+Ctrl+Tab

    Hold Win+Ctrl and tap Tab to walk your workspaces in most-recently-used order, then let go to land. One tap takes you back to wherever you just were, and focus lands on the window you were last using there, so you arrive typing.

  • Find anything open, on any desktop

    Win+Alt+Space opens a search over every window, every browser tab and every VS Code tab on every workspace. Type a few letters in any order, and the results sit under the workspace they are in. Enter takes you straight there, to the tab and not just its window.

  • Your windows along the top of each screen

    A thin strip across the top of every screen lists that screen's windows in the workspace you are in, with their titles. Pin a workspace you keep jumping into and it gets an item at the end of every strip and a button on the taskbar: one click takes you in, the next takes you back.

  • Tile a workspace with one button

    The tile button at the top of the bar lays the workspace's windows out on each screen. Drop a tile on the edge of another to put it above, below or beside it, or on its middle to swap the two. Drag the line between tiles to resize them. The layout you make is kept, across restarts too.

  • See where your time went

    Manage's Time tab shows how long you spent in each workspace today, this week and over the last thirty days, by group or by workspace. Only keyboard and mouse input counts, so a desktop left open overnight adds nothing.

  • See what is waiting elsewhere

    Rest on an icon and a card shows the window's title, its app and workspace, and for a window on another desktop, a picture of it at a quarter size.

  • It remembers where windows belong

    Move a window to a workspace by hand and that is where the app goes next time. Workspaces survive reboots. Deskbar never launches anything on its own, and unless you tile a workspace it leaves every window's size and position alone.

  • Arrange the bar by dragging

    Turn on Arrange workspaces and drag rows to reorder them, or drop one onto another to make a group. Fold a workspace you are not working in down to its name and a window count; the amber dot still shows when something there wants you.

  • A task board on the bar

    Type a note into the box at the bottom of the bar and it lands on the workspace you are on. Mark tasks important or urgent to sort them into Covey's four quadrants, give one subtasks, or snooze it until tomorrow. The tasks panel adds comments, a Matrix view and stats on how the work is going.

  • Floating or docked

    The bar floats where you drop it, docks to a screen edge, or straddles two screens. It carries your taskbar pins, the clock, volume and notifications, so Windows' own taskbar can stay on auto-hide, and apps flashing for attention get an amber dot on the bar instead of holding that taskbar up.

  • Drive it from scripts

    While it runs, Deskbar keeps a small command file that hands commands to the running copy, and nearly everything on the bar's menus has one. A coding agent that has just set up a git worktree can give it a workspace of its own and move the editor there: 

    & "$env:APPDATA\Deskbar\deskbar.cmd" move wt-login --create --title wt-login --wait 20

  • Nothing installed, nothing sent

    One exe and no installer. Deskbar writes nothing outside your own user profile and sends nothing about you. It checks for updates, which can be switched off in Manage, and a problem report leaves your computer only when you press Send.

I built it for myself and it is on my screen all day, every day. A bar you look at all day has to be exactly right or it grates, so the tiny details get the attention.

Bring everyone at work to Claude.

Deskbar started as one person's desk for running many Claude sessions at once. The same task board is an easy way in for people who have never opened a terminal: they write what they need as a task, and the session's questions come back to that task.

Download

One file. No installer.

Deskbar is one portable exe, published on GitHub with every release.

Get started

  1. Download Deskbar-<version>-win-x64.exe from the latest release on GitHub.
  2. Put it somewhere permanent, such as C:\Users\<you>\Programs\Deskbar\, not your Downloads folder. "Start with Windows" remembers where the exe lives.
  3. Double-click it. Deskbar opens no window; it goes straight to the tray and puts the bar on screen.
  4. Left-click the tray icon to open Manage and create your first workspace.

The exe is not code-signed yet, so Windows SmartScreen warns the first time you run it. Choose More info, then Run anyway. Or build it yourself from the source.

Download the latest release

Requirements

  • Windows 11, build 22000 or newer
  • x64
  • Nothing else. The .NET runtime is bundled in the exe.

Windows only, by design. Deskbar is built on Windows' own virtual desktops and the taskbar's per-desktop filtering, so there is no macOS or Linux version waiting to be written.
