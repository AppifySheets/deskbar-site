Privacy

Last updated 22 November 2026

Deskbar, the app, collects nothing about you and sends nothing about you anywhere unless you send a problem report yourself. This is true of both copies: the one from GitHub and the one from the Microsoft Store. Your workspaces, window names, rules and time per workspace stay in files under %APPDATA%\Deskbar on your own computer. To show your windows on the bar, the app reads the titles of the windows you have open. That happens on your computer only, and none of it is sent anywhere. The only network requests either copy makes are the ones described below.

If Deskbar ever starts collecting diagnostic or usage data, this page will say what is collected and how to turn it off before the release that starts it.

The copy from GitHub

Apart from problem reports you send, its only network traffic is the update check: every five minutes, and whenever you choose Check for updates, it asks GitHub whether a newer release exists, and accepting an update downloads it from GitHub. Those requests reach GitHub like any other web request, with your IP address, and GitHub's own privacy statement covers them. You can turn the automatic check off in Manage.

The Microsoft Store copy

It never contacts GitHub for updates. It asks the Microsoft Store for its own licence, to know whether you own the Deskbar Pro add-on: once when it starts, and every five minutes while the automatic check is on. The answer stays on your computer; it decides only whether the bar shows its reminder about Pro. On the same five-minute timer, and whenever you choose Check for updates, it asks the Store whether an update exists, and the Store installs it. Those requests go to Microsoft, under Microsoft's privacy statement. You can turn the automatic check off in Manage.

Buying Deskbar Pro

Deskbar Pro is an add-on sold through the Microsoft Store, with Microsoft as the reseller and merchant of record, so your payment details go to Microsoft under Microsoft's privacy statement. There is no licence key: the Store's licence for the add-on on your Microsoft account is what makes a copy Pro. Microsoft does not send us your name or email address for an ordinary purchase. We see only total sales and payouts.

Reporting a problem

Report a problem, on the tray menu and the bar's menu, sends a report only when you press Send, and needs no account or sign-in. It carries what you type, any screenshots you add, the contact line if you fill it in, the app's version and Windows build, whether the copy is from the Store, and whether it has Deskbar Pro. The debug dump is ticked by default: it describes your screens, the bar and every window on them, titles included. View what it contains opens it in Notepad before anything is sent, and you can untick it.

The report goes over https to report.deskbar.app, a small relay we run on Cloudflare, which files it in a private GitHub repository that only the Deskbar team can read. It is never posted anywhere public. Those services see the request like any other, with your IP address, under Cloudflare's and GitHub's privacy statements. We use a report to fix the problem and, if you left a contact, to answer you. If it cannot be sent, it is saved under %APPDATA%\Deskbar\reports on your computer and goes nowhere until you choose Try again.

This site

This site sets no cookies and runs no scripts or analytics. It is hosted on GitHub Pages, which logs visitors' IP addresses for security, under GitHub's privacy statement. If you write to hello@deskbar.app, your message and address are used to reply to you and for nothing else.
